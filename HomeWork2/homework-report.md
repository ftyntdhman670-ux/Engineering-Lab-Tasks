# الوظيفة الثانية: تطبيق React الأول

## متطلبات التسليم
- [x] إنشاء مشروع React يعمل بدون أخطاء.
- [x] تقسيم التطبيق إلى مكونات: Header, Content, Part, Total.
- [x] استخدام الـ Props لتمرير البيانات بشكل صحيح.

## أسئلة للمناقشة
1. **لماذا نقسم التطبيق إلى مكونات صغيرة؟**
   - لتسهيل صيانة الكود، وإمكانية إعادة استخدام المكونات في أماكن أخرى، وجعل بنية المشروع واضحة ومفهومة.

2. **ما الفرق بين `<Hello />` و `hello`؟**
   - `<Hello />` هو استدعاء لمكون (Component) في React، بينما `hello` هي مجرد كلمة أو متغير نصي عادي.

3. **ماذا يحصل إذا نسينا `export default App`؟**
   - لن نتمكن من استيراد المكون في ملفات أخرى (مثل `index.js`) وسيعطي النظام خطأ بأن المكون غير موجود.
